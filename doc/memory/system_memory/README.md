# 系统四表

schema.js 定义四表与向量存储协议；protocol.js 提取 Companion 的四表初始提案和冷读取约束；repository.js 承担事务和 CRUD；service.js 运行两阶段总结；temporary.js 管临时分段总结。prompts/ 存放提取、更新、合并的 Markdown。

common 下集中数据库连接、跨模块向量操作和冷热状态机，避免每个功能重复开库。memory/db.js 仅为旧调用点的兼容出口，功能模块直接导入各自依赖，不反向依赖大出口。

四表支持 hot/cold/freeze，旧约束事务迁移保留数据、索引、触发器及自增序号。冻结后保留向量但不进入任何模型读取或更新路径，管理员显式解冻后才可编辑。

第一轮请求前取事实快照；第二阶段只接受已recall冷人物/物品的定向变化字段或固定unchanged。全部验证后一个事务核验目录/正文/状态，提交初次提案、定向更新、批次成功、来源覆盖与临时总结状态。同角色任务串行化；模型期间人工变化拒绝整批，纯向量重建不视为事实变化。
