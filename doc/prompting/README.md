# 上下文编排

app/prompting将选定的WRX预设、宿主素材、角色记忆和历史编译为messages。编译器处理传入快照，不直接查询数据库或调用模型；宿主接入层负责提供素材。

## 内容顺序

条目按可见列表顺序展开，可选择文本、宏来源、消息角色、启停或删除规则。结构化宏保持完整消息结构，不把工具调用/结果转成普通文字。

dsh.full提供宿主原生提示词全文：先逐分块应用删除规则，再按原顺序合为一条提示词消息。独立sections/contexts也可分别选取；同一内容不要重复加入组合及独立来源。工具schema始终通过API tools发送。

wrx.diaries、wrx.system_memory、wrx.ai_notes、wrx.user_profile等来源允许用户明确安排位置。常用补齐只添加七个缺少来源，不自动加入工具目录、不覆盖个人正文。未启用WRX的角色保留原生DSH请求。

## 历史窗口

- turns：仅当前会话最近N次真实用户输入。
- duration：角色范围内最近固定分钟数。
- since：角色范围内固定起点之后的内容。

当前会话完整保留本回合工具调用及结果；其他会话只提供带来源和时间的用户/助手正文，不重放它们的工具链。只有成功总结且明确记录覆盖关系的流水可按选项排除。

DSH压缩摘要根据surface与shadowedSeqs边界展开并排除被覆盖原文，按覆盖结束时间归入历史。未知压缩范围不臆造覆盖关系。没有session变更归属或混合角色历史重分配功能。

## 回合快照

真实用户或定时输入开始新回合，采样角色、预设、时间、画像、热记忆和召回。工具续轮、纯通知继续使用同回合快照，只追加原生轨迹；同轮压缩只更新历史边界，不重复向量召回。

时间标签由WRX呈现层提供，默认关闭，只给有原始事件时间的真实用户消息加标签，不修改存储。current_time/current_date在新回合生成并随续轮冻结。不安装独立time或late排序补丁。

## 模型协议

原生assistant reasoning、replayState及工具签名保持结构化。是否向模型回放历史思考由DSH适配器决定；WRX不将其拼入可见正文。模型已经返回的普通文本不按语气猜删。

模型适配器可能再次转换system消息。WRX的编排预览和抓包默认只证明适配器输入，不能代替供应商最终HTTP验证。供应商策略见[兼容说明](../integrations/dsh/PROVIDER_COMPATIBILITY.md)。

## 宿主接入

integrations/dsh/request-hook注册编排器。发行包的patches/request-hook生成器只提供请求冻结前的交接点，统一交付角色Preset、原始时间、工具元数据及压缩范围，并收回messages和温度参数。详见[接入说明](../integrations/dsh/README.md)。
