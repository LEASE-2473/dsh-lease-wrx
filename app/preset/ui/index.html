      使用说明 · 不用懂宏，也能排列上下文
      
① 自己写规则：点“＋普通条目”，填写正文。② 加入动态资料：选择中文内容，点“＋加入所选内容”，无需填写正文或插入宏。③ 拖动排序，预览后保存预设；首次使用还要启用统一编排并保存编排设置。

      
推荐顺序：固定规则 → DSH工具/技能等内容 → 热日记 → 历史对话 → 用户信息与画像、助手信息与画像、动态记忆、召回 → 本次用户输入。每项都是独立内容块，可以移到后面。

      
历史对话就是上方历史窗口筛选出的消息。最近N次只取当前会话；时间范围取同角色各会话，其他会话只含对话文本。当前输入不属于历史；建议把“本次用户输入”放在最后，未添加时系统会自动保留。

      
旧 Chat History 默认包含历史＋本次输入。要把画像放在两者之间，请在它的“这条发送什么”选择“历史对话”，再把画像和“本次用户输入”依次放在后面。不要再添加第二份历史。

      
旧 Character Definitions 对应助手信息与画像，User Definitions 对应用户信息与画像，并非无用；可直接拖到后面，或用中文来源替换。World Info Before/After 当前没有默认内容提供，可关闭。旧标记正文不参与发送。

      
五项独立来源：用户信息（静态）、用户画像（动态·完整）、用户画像（动态·匹配）、角色信息（静态）、角色画像（动态·完整）。信息放前面，画像可放历史后面。旧User/Character Definitions仍是组合，请改选静态信息，再单独添加画像，避免重复。

      
完整模式确实发送全部画像；用户匹配模式由代码检查当前及上一条用户输入中的关键词，只发送命中条目，无命中不发送，不夹带称呼和常驻信息。用户两种画像按需选一种。角色画像目前只有完整模式，没有匹配功能。“动态”表示每轮新输入读取最新资料，工具续轮沿用快照。

      
动态记忆旧组合仍包含静态用户资料、匹配画像、四表热记忆、外出与AI笔记；使用独立项时请关闭旧组合以免重复。信息的“静态”表示资料类别，人工修改后下一轮仍会更新。

      
“补齐常用内容”添加八项建议内容，不是全部必需项；已存在（包括关闭）的项不会重复添加。DSH独立内容在宿主收到请求后才能被发现，重新读取可更新目录。真正工具参数仍由模型协议发送。

      
高级用法：普通正文可插动态变量，例如“现在是 {{current_time}}”。选择自动内容来源后无需再插变量；历史和本次输入只能独占条目。预览不调用模型，缺失素材会提示；供应商可能合并system消息，上方兼容设置可调整。
